### Day 4 – Role Prompting

**What I learned:**

Role prompting means giving an AI model a specific role so that it responds according to that role.

**Experiment:**

I used the same user prompt: "Explain what an API is."

I tested it with three different roles:

1. **Teacher:** Explained API using simple language and real-world examples.
2. **Software Engineer:** Provided technical details about HTTP methods, REST, GraphQL and API architecture.
3. **Interviewer:** Explained API from an interview perspective and provided common follow-up questions.

**Conclusion:**

Changing the system prompt changes how an AI responds, even when the user prompt remains the same.

This helped me understand the importance of system instructions and role prompting.
