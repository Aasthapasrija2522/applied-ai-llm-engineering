# Day 5 – Practical Prompting Techniques

## What I Learned Today

Today I learned about different practical prompting techniques and how we can use LLMs to perform common tasks through well-written prompts.

### 1. Summarisation
- Learned how to convert long text into shorter and meaningful summaries.
- Understood how to preserve important information without adding unnecessary details.

### 2. Classification
- Learned how to classify text into predefined categories.
- Practised sentiment classification using Positive, Negative and Neutral labels.

### 3. Information Extraction
- Learned how to extract specific information such as name, email and college from a given text.
- Understood how to handle missing information using `null` instead of making up details.

### 4. Structured Responses
- Learned how to get responses in a specific format such as JSON.
- Understood why structured outputs are useful when working with APIs and Python applications.

### 5. Good Prompts vs Bad Prompts
- Understood that clear and specific instructions produce better results.
- Learned to mention the task, constraints and expected output format in a prompt.

## Practical Implementation

Created three reusable Python functions using the Gemini API:

1. `summarise_text()` – Summarises the given text.
2. `classify_text()` – Classifies text based on sentiment.
3. `extract_information()` – Extracts specific details and returns them in JSON format.

## Key Takeaway

Today I understood how prompting techniques can be used in real applications. I also learned how to make LLM responses more useful and structured by giving clear instructions and defining the expected output.
