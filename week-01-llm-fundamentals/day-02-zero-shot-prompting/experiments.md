# Day 2 – Zero-shot Prompting

### 1. Summarisation
- Tried summarising text using a simple prompt.
- Then asked for the summary in 2 bullet points.
- **Observation:** The summary changed according to the instructions.

### 2. Classification
- Asked Gemini to identify the sentiment of a customer review.
- Then asked it to give a reason along with the sentiment.
- **Observation:** Adding a small instruction made the response more useful.

### 3. Question Answering
- Asked a question using a basic prompt.
- Then modified the prompt to get an answer with examples.
- **Observation:** The second prompt gave a more detailed and organised answer.

### Conclusion
Today, I tried different prompts for summarisation, classification and question answering. I noticed that changing the instructions, even a little, can change the way Gemini responds.
