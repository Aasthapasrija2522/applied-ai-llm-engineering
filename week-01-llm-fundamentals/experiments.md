 Day 1 – Practical Experiments

 Experiment 01: First Gemini API Call

 09 November 2026

Objective
To connect Python with Google's Gemini API and understand how we can interact with an LLM through code.

What I Did
1 Created a new GitHub repository.
2 Set up my local project folder.
3 Created and activated a Python virtual environment.
4 Installed `google-genai` and `python-dotenv`.
5 Generated a Gemini API key and stored it in the `.env` file.
6 Created a Python script to send prompts to Gemini and get responses.

My Understanding

API: A way through which two applications communicate with each other. Yahan Python aur Gemini ke beech communication ho raha hai.
API Key: A secret key used to access the API. Isse code mein directly expose nahi karna chahiye.
Gemini Client: It helps us connect our Python application with Gemini.
Prompt:The question or instruction we give to the AI.
Response: The answer generated by the AI.
Environment Variables: Values like API keys that we store separately from our actual code.

 Challenges & Mistake:

1. Initially, I was confused about how Python would access the API key stored in .env.
2. I wasn't clear about the difference between .env and .env.example.
3. Faced a model availability error because the model name I initially used was not available.
4. Later, encountered a connection error (`WinError 10053`).
5. One small mistake: I entered my question directly in PowerShell instead of waiting for the Python program to ask for input.

Questions I Had

1. What exactly is an API, and how does it work?
2. How does Python communicate with Gemini?
3. Why do we need an API key?
4. How does `load_dotenv()` read values from the `.env` file?
5. Why do we initialize a Gemini client before making an API call?
6. What's the difference between using Gemini on its website and calling it through Python?
7. Does every API call cost money?
8. Does changing the model name affect the response?

Key Learnings

I understood that we can integrate LLMs into our own Python applications instead of using them only through their websites.

I also got familiar with the basic flow:

Python Code → Gemini Client → API Request → Gemini Model → Generated Response

 Result
Basic project setup and API integration code completed. Final successful API response is yet to be confirmed.
